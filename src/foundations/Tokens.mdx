# Tokens

Neobrutalism: flat colour, pitch-black outlines, hard shadows with no blur.
Use the **Theme** switch in the toolbar to check light and dark. Rules live in `docs/design-direction.md`.

## Brand colours

Same in light and dark. Text on them is always ink (except white on purple).

<div className="not-prose my-4 grid grid-cols-2 gap-4 sm:grid-cols-4">
  {[
    ['lime', 'bg-lime', 'bg-lime-soft'],
    ['purple', 'bg-purple text-white', 'bg-purple-soft'],
    ['orange', 'bg-orange', 'bg-orange-soft'],
    ['pink', 'bg-pink', 'bg-pink-soft'],
  ].map(([name, solid, soft]) => (
    <div key={name} className="overflow-hidden rounded-lg border-2 border-ink text-ink shadow-brutal-sm">
      <div className={`${solid} p-3 font-display text-sm`}>{name}</div>
      <div className={`${soft} border-t-2 border-ink p-2 text-xs`}>{name}-soft</div>
    </div>
  ))}
</div>

## Contrast (WCAG AA needs 4.5:1 for text)

| Pair | Ratio |
| --- | --- |
| ink on cream | 19.3 |
| ink on lime | 17.0 |
| ink on orange | 8.4 |
| ink on pink | 6.7 |
| white on purple | 5.9 |
| muted text on cream | 6.2 |
| cream on dark background | 17.9 |
| muted text on dark background | 7.7 |
| lime on dark background | 15.7 |
| destructive on cream / dark | 4.7 / 6.5 |

**Never** put lime, orange or pink *text* on a light background. Use them as fills with ink text.
