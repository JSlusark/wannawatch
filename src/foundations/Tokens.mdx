# Tokens

Neobrutalism: flat colour, pitch-black outlines, hard shadows with no blur.
Use the **Theme** switch in the toolbar to check light and dark. Rules live in `docs/design-direction.md`.

## Colour ramps

Same in light and dark. Every colour has 9 shades: **100** is the lightest, **500** is the
brand colour (the button fill), **900** the darkest. Pick from these; never invent a shade.
`lime`, `purple`, `orange` and `pink` on their own mean the 500; `-soft` means the 200.

- Ink text works on 100–500 of every ramp (white on purple 500 and darker).
- Coloured *text* on a light background: 700 or darker.
- Coloured text on the dark background: 300–500.

## Contrast (WCAG AA needs 4.5:1 for text)

| Pair | Ratio |
| --- | --- |
| ink on cream | 19.3 |
| ink on lime | 17.0 |
| ink on orange | 8.4 |
| ink on pink | 6.7 |
| white on purple | 5.9 |
| muted text (grey-600) on cream / muted | 6.2 / 5.5 |
| cream on dark background (grey-950) | 17.8 |
| muted text (grey-400) on dark background / muted | 7.3 / 5.7 |
| lime on dark background | 15.7 |
| destructive on cream / dark | 5.5 / 6.5 |
| lime / orange / pink 700 on cream | 4.8 / 5.3 / 5.9 |
| genres (grey-300) on the poster scrim | 12.0 |

**Never** put lime, orange or pink 500 *text* on a light background. Use them as fills with
ink text, or use the 700 shade for text.
