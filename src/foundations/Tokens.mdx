# Tokens

A **design token** is a named design decision: "the lime of the brand", "the big hard shadow".
Each one is a CSS variable in `src/app/globals.css`, and Tailwind turns it into class names.
Change the variable and every component that uses the class changes with it.

Neobrutalism: flat colour, pitch-black outlines, hard shadows with no blur. Rules live in `docs/design-direction.md`.

## How to read this page

Every token shows three names:

**Colour classes.** The variable `--color-NAME` gives you every colour class, not only `bg-`:
`bg-NAME` (fill), `text-NAME` (text), `border-NAME`, `ring-NAME`, `outline-NAME`, `fill-NAME` and `stroke-NAME` (SVG icons), `decoration-NAME` (underlines).
Add `/50` for 50% opacity, e.g. `bg-lime-500/50`. The cards below show `bg-` for fills and `text-` for text colours.

**Where to change what.**
- Colour ramps, shadows, motion: the `@theme` block. Same in light and dark.
- Theme colours (background, primary…): `:root` for light and `.dark` for dark. They point at ramp colours.
- Font families and radius scale: the `@theme inline` block. *Inline* means "read the value where it's used", which is what lets theme colours switch with dark mode.

## Colour ramps

Same in light and dark. Every colour has 9 shades: **100** is the lightest, **500** is the
brand colour (the button fill), **900** the darkest. Pick from these; never invent a shade.

- Ink text works on 100–500 of every ramp (white on purple 500 and darker).
- Coloured *text* on a light background: 700 or darker.
- Coloured text on the dark background: 300–500.

## Theme colours

These change with light and dark, so each one shows both. Components should use these names
(`bg-primary`, not `bg-lime`) whenever the colour has a *role*: then dark mode works by itself.

The variable you edit is the short one (`--primary`), in `:root` for light and `.dark` for dark.
Tailwind reads it through `--color-primary`, which is what makes `bg-primary` exist.

## Hard shadows

Offset down-right, zero blur, fully opaque. Their colour is `--shadow-ink`: ink in light mode, cream in dark mode.

The light/dark labels show the offset (right, down). **`shadow-…`** draws a rectangle behind the box. **`drop-shadow-…`** follows the shape itself (icons, text).

## Spacing

One base step, `--spacing`, and every spacing class is a multiple of it: `p-4` = 4 × 0.25rem = 16px.
The same numbers work for padding (`p-`, `px-`, `py-`), margin (`m-`), gaps (`gap-`), sizes (`w-`, `h-`, `size-`) and positions (`top-`, `inset-`).
Change `--spacing` and the whole layout scales.
